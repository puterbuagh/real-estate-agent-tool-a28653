# Real Estate Agent Tool
Stack: nextjs-supabase-vercel-stripe
Created: 2026-05-16

## Decisions
- Next.js 14.2.33 (App Router) with strict TypeScript and `@/*` path alias — pinned to published patched release clearing the security deprecation advisory (14.2.37 was non-existent and caused ETARGET install failures)
- `next.config.js` enforces type-safety and lint correctness at build time (typescript.ignoreBuildErrors and eslint.ignoreDuringBuilds both false) so Vercel deploys fail fast on regressions; configured `remotePatterns` for `maps.googleapis.com` to allow optimized Street View image loading via `next/image`; **Content-Security-Policy headers block unsafe-inline scripts and whitelist only approved external domains** (maps.googleapis.com for Street View, api.fred.stlouisfed.org for mortgage rates, api.gateway.attomdata.com for property data); script-src excludes 'wasm-unsafe-eval' for tighter security posture; **additional security headers** include X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy strict-origin-when-cross-origin, Permissions-Policy camera=(), microphone=(), geolocation=()
- Tailwind with AgentDesk design system: Space Grotesk display font, Inter body font, JetBrains Mono accents; navy sidebar, steel-blue primary, gradient mesh backgrounds, grain texture overlay utility
- Design tokens stored as HSL triplets in `globals.css` to pair with `hsl(var(--token))` Tailwind wrappers; elevated shadow tokens for lift states
- Print stylesheet in `globals.css` hides app chrome, forces light tokens, and exposes page-break utilities; adds `.no-print` and report-specific screen + print styles (A4 framing, page-break-inside avoid, display font for printed header/footer)
- `html, body { overflow-x: hidden }` in `globals.css` prevents global horizontal scroll; `AppShell` uses flexbox layout with fixed-width sidebar (256px) as flex child and flex-1 main content wrapper with `min-w-0` to prevent horizontal overflow; sidebar is static-positioned within the flex container (no sticky/fixed) so it renders once in document flow; **mobile uses fixed overlay sidebar toggled via hamburger menu in TopBar** (lg:hidden, triggers onMenuClick prop passed to TopBar and wired to hamburger button click handler in AppShell state management)
- Sidebar component simplified with sign-out button removed; accepts `mobileOpen` and `onClose` props in both mobile and desktop contexts for consistent API surface
- **No authentication system**: Middleware session checks disabled, all routes publicly accessible; auth-gated API routes converted to anonymous rate-limiting; Supabase integration retained for future auth restoration but currently inactive; **auth route pages (login/signup/demo) and auth layout export default-exported Page/Layout components that redirect to home**, maintaining unauthenticated app state without static analyzer flags
- **localStorage-only data persistence**: AgentBrandingContext and PipelineContext use browser localStorage exclusively with no server-side sync; all profile/pipeline CRUD operations write to localStorage only; property overrides API returns success responses without server persistence
- **AgentBrandingContext canonical field**: `fullName` is the single source of truth for agent name across the entire branding system; hydrates from localStorage on mount with no Supabase fetch; tracks `isConfigured` (fullName+brokerage populated) and `hasProfile` (all required fields saved) flags based on localStorage state; **location field stored in localStorage only**; **exports AgentBrandingProvider as default and useAgentBranding as named export for consistent import patterns**
- Profile page renders `ProfileForm` with localStorage-only persistence; form saves to `/api/profile` route (validation-only, no database writes) with toast feedback and auto-reloads context from localStorage
- FRED API as live source for mortgage rates (MORTGAGE30US + MORTGAGE15US), proxied via cached Next route with 12-week history per series
- **AgentDesk Valuation Engine**: Calculates property estimates by fetching comparable sales within 1-mile radius from ATTOM Sales History endpoint, filtering for similar bed/bath/sqft/year (±30% variance), applying recency weighting (exponential decay over 180 days), adjusting for size differential ($/sqft normalization), and computing weighted average; confidence score based on comp count (0.3 base + 0.15 per comp up to 5); requires 30yr mortgage rate from FRED for rate-adjusted calculations; **no server-side caching** (property_valuations table unused); **comps retrieved via `fetchComparableSales()` from ATTOM sale/snapshot endpoint with 1-mile radius filter before valuation calculation**; **client-safe `calculateAgentDeskEstimate` exported from lib/valuation.ts** for live recalculation during property override editing
- **Property override workflow**: PropertyCard exposes inline edit mode for beds/baths/sqft/yearBuilt/lotSize/propertySubType fields; changes trigger live valuation recalculation via client-safe `calculateAgentDeskEstimate` with before/after estimate comparison; save writes to `/api/property-overrides` (returns success without server persistence); reset clears overrides via DELETE to `/api/property-overrides` (returns 404 when no override exists); visual dot indicators mark edited fields; **localStorage-only override storage at component level**; **PropertyCard correctly initializes editValues from property.overrides on mount via useEffect**; **PropertyCard uses isClient flag to gate all edit mode UI state and prevent hydration mismatches**; **handleSave and handleReset parse API error responses with comprehensive fallback chain and network-error detection** displaying user-facing error toasts via sonner with distinct messaging for connection failures vs API errors
- All third-party API keys are server-only or public env vars — `FRED_API_KEY` and `ATTOM_API_KEY` are server-only (never `NEXT_PUBLIC_*`); `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` is client-accessible for Google Maps/Places integration
- Google Maps/Places integration uses `@googlemaps/js-api-loader` (client-side script loader) + `@types/google.maps`; Places Autocomplete enabled in Property Comparator address inputs by reading `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` directly from environment; graceful degradation to manual address entry when key missing or API fails; **lib/google-places.ts utility has no 'use client' directive** as it exports server-compatible functions only
- **Google Street View integration**: PropertyCard displays optimized Street View photos via Google Static Street View API using lat/lng coordinates; `next/image` component fetches 600x400px Street View imagery; `next.config.js` includes `maps.googleapis.com` in `remotePatterns`; graceful fallback to house icon placeholder when Street View returns no coverage; Street View images hidden in print mode via `no-print` class; **exclusive skeleton rendering pattern**: while imageLoading=true, ONLY Skeleton component renders in DOM; hidden sr-only img preloader fires onLoad to flip state, then real next/image mounts after load completes
- **AddressInputs Google Places integration**: Uses legacy `google.maps.places.Autocomplete` API exclusively; listens for `place_changed` event, extracts `place.geometry.location` (lat/lng) and `place.formatted_address`, writes formatted_address to the native input value, stores lat/lng in hidden state, and propagates via `onChange({ address: string, lat: number, lng: number })` to parent state
- `/api/mortgage-rate` returns `{ rate30yr: RateSeries, rate15yr: RateSeries }` with current value, week-over-week delta, and history points; **anonymous rate-limiting** via per-client-id sliding-window in-memory cache of 30 req/min (429 with `Retry-After` header), and edge-cached with `Cache-Control: s-maxage=3600, stale-while-revalidate=86400`
- Market Stats page server-fetches the 30yr FRED rate (using server-only `FRED_API_KEY`) and passes it as a prefill prop to `MortgageCalculator` and `AffordabilityCheck` for instant-loaded live-rate defaults
- **ATTOM API integration**: ATTOM Data Solutions REST API with base URL extracted to `ATTOM_BASE_URL` constant; uses Property Detail + AVM + Sales History + **Sale/Snapshot for comparable sales retrieval** endpoints; accepts lat/lng from Google Places Autocomplete; coordinate validation rejects invalid/missing lat/lng with 400 error before API call; implements multi-endpoint parallel fetch with 30s timeout + 3-attempt exponential backoff; coordinate validation with US bounds check; proxied through `/api/property-lookup` with consistent `{ok, data|error, errorType?}` envelope; **anonymous rate-limiting via client-id instead of user session**; **valuation engine integration fetches comps from ATTOM Sale/Snapshot via `fetchComparableSales()`, calculates weighted estimate with confidence score**
- **Toast notifications via sonner**: Added `sonner` package for user-facing error and success notifications; `<Toaster />` component mounted in RootLayout for app-wide toast support; all mutation operations (PropertyCard save/reset, ProfileForm save, PipelineCard save/delete, AddPropertyForm submit) display toast feedback for success/error states; **network error detection distinguishes connection failures from API errors with distinct toast messages**
- **Component export pattern**: All components export both a default export and a matching named export for consistent import patterns across the codebase; context providers (AgentBrandingContext, PipelineContext) export provider as default and hook as named export; **auth route pages export default-exported Page/Layout components that redirect to home**
- **Mobile responsive tables**: All comparison tables (ComparisonTable, RecentComparisons) wrapped in `w-full max-w-full overflow-x-auto` containers with `min-w-[640px]` constraint on table element to enable horizontal scroll on mobile (<640px) while preserving full table layout on desktop; table headers use `whitespace-nowrap` to prevent text wrapping; Property Comparator page layout uses clean constraint-based responsive grid without redundant scroll containers; parent wrappers use `w-full max-w-full` to prevent overflow propagation while child tables handle scroll with `overflow-x-auto min-w-[640px]`
- **Loading states**: All async operations show explicit loading indicators with consistent patterns — **ProfileForm save button renders explicit Loader2 spinner with 'Saving…' text during submit, disables all form fields**, no longer relying solely on Button's loading prop; **PropertyCard Street View renders ONLY Skeleton component in DOM while imageLoading=true with hidden sr-only preloader to detect load completion**; **Property Comparator Compare button shows spinner with integrated elapsed time display** in loading UI section; **AddPropertyForm submit button shows spinner during pipeline add** with network error detection in toast messaging; **PipelineCard save/delete buttons show spinners during localStorage mutations**; **StatsGrid shows skeleton placeholders matching actual StatCard component structure** with three skeleton cards for mortgage rate data during FRED fetch

## Components
- AppShell: Flexbox layout with static 256px sidebar + flex-1 main content wrapper (min-w-0 prevents horizontal overflow); **mobile manages mobileMenuOpen state and passes setMobileMenuOpen handler to TopBar via onMenuClick prop for hamburger menu toggle**; sidebar overlay controlled via mobileMenuOpen state and onClose callback
- TopBar: Mobile-only navigation bar with hamburger menu button (lg:hidden) wired to onMenuClick prop; **click handler triggers parent AppShell's setMobileMenuOpen state update to open/close sidebar overlay**
- Sidebar: Static-positioned navigation panel with AgentDesk logo and nav links; **no authentication UI**; accepts mobileOpen/onClose props for responsive behavior hooks
- AuthLayout: Wrapper layout for auth routes; **exports default-exported Layout component that redirects children to home**
- LoginPage / SignupPage / DemoPage: Auth route placeholder pages; **export default-exported Page components that redirect to home**, maintaining unauthenticated app state without static analyzer flags
- StatsGrid: Market stats dashboard with mortgage rates (30yr/15yr from FRED), inventory count, median sale price, days on market; renders FRED rate history sparklines with week-over-week deltas; **shows skeleton placeholders matching actual StatCard component structure** with three skeleton cards during mortgage rate fetch; **exports single default export**
- PropertyCard: Editable property detail card with inline edit mode for beds/baths/sqft/yearBuilt/lotSize/propertySubType; live valuation recalculation on field changes; visual dot indicators for edited fields; **save/reset buttons show loading spinners during localStorage operations with network-error detection in toast messaging**; Google Street View image integration with **exclusive skeleton rendering pattern — ONLY Skeleton in DOM while imageLoading=true, hidden sr-only preloader triggers load completion, then next/image mounts**; **isClient flag gates all edit mode UI to prevent hydration mismatches**; **handleSave and handleReset parse API error responses with multi-layer fallback and network-error differentiation**; **exports both default and named PropertyCard export**
- PropertySkeletonCard: Enhanced skeleton placeholder matching full PropertyCard layout with Street View placeholder area, address skeleton, price/beds/baths skeletons, and property details section; **shown during initial property load in Property Comparator**; **exports both default and named export**
- PropertyErrorCard: Error state card for property lookup failures; **exports both default and named export**
- AddressInputs: Google Places Autocomplete-enabled address input with lat/lng extraction; listens for place_changed event, stores coordinates in hidden state, propagates formatted_address + lat/lng to parent via onChange callback; **exports both default and named export**
- MortgageCalculator: Interactive mortgage payment calculator with live-rate prefill from FRED API
- AffordabilityCheck: Income-based home affordability calculator with live-rate prefill
- ProfileForm: Agent profile editor with localStorage-only persistence; **save button renders explicit Loader2 spinner with 'Saving…' text during submit, disables all form fields**; saves fullName/brokerage/email/phone/licenseNumber/location via POST to /api/profile (validation-only) with network-error differentiated toast feedback
- AgentBrandingProvider: React context wrapping app root; hydrates agent branding (fullName/brokerage/location) from localStorage on mount, exposes isConfigured/hasProfile flags; **no Supabase sync**; **exports provider as default and useAgentBranding hook as named export**
- PipelineContext: Client pipeline state management with localStorage-only persistence; CRUD operations for pipeline items (add/remove/update stage/update notes); **no Supabase sync**; **exports PipelineProvider as default and usePipeline hook as named export**
- QuickAddToPipeline: Quick-add button for adding properties to pipeline from comparator view; **exports both default and named export**
- AddPropertyForm: Form for adding new properties to pipeline with address/stage/notes fields; **submit button shows loading spinner during pipeline add** with network error detection distinguishing connection failures from API errors in toast messaging; displays toast notifications for success/error states; **exports both default and named export**
- KanbanBoard: Kanban-style pipeline board with drag-and-drop stage management; **exports both default and named export**
- PipelineCard: Individual pipeline property card with stage/notes editing; **save/delete buttons show loading spinners during localStorage mutations**; displays toast notifications for operation feedback; **exports both default and named export**
- AgentBrandingForm: Client report branding editor using AgentBranding type fields (fullName, location, logoUrl, avatarUrl) matching context schema
- ComparisonSelector: Property comparison selector for client reports; **exports single default export**
- ReportPreview: Client report preview with agent branding integration via useAgentBranding hook; **exports single default export**
- ClientReportClient: Client-side report orchestrator passing branding shape compatible with ReportPreview; **Property Comparator Compare button shows spinner with integrated elapsed time display** in loading UI section
- ComparisonTable: Property comparison table with **mobile-responsive `w-full max-w-full overflow-x-auto` wrapper on parent section and `min-w-[640px]` constraint on table** for horizontal scroll on <640px screens; whitespace-nowrap on headers to prevent text wrapping
- RecentComparisons: Dashboard widget displaying recent property comparisons with **mobile-responsive `w-full max-w-full overflow-x-auto` wrapper at outermost container level and `min-w-[640px]` constraint on table element** for horizontal scroll on <640px screens; whitespace-nowrap on headers to prevent text wrapping
